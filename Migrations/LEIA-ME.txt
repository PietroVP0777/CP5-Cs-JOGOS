Esta pasta vai receber os arquivos de Migration do EF Core.

Eles NÃO estão pré-gerados neste pacote porque o EF Core precisa gerá-los
usando a ferramenta "dotnet ef" na sua própria máquina (ela lê o SDK do
.NET 10 instalado localmente para montar o snapshot do modelo corretamente).

Para gerar a migration inicial, na pasta do projeto rode:

    dotnet tool install --global dotnet-ef   (só na primeira vez, se ainda não tiver)
    dotnet ef migrations add CriacaoInicial

Isso vai criar 3 arquivos aqui dentro:
    20xxxxxxxxxxxx_CriacaoInicial.cs
    20xxxxxxxxxxxx_CriacaoInicial.Designer.cs
    AppDbContextModelSnapshot.cs

Depois é só rodar "dotnet run" — o Program.cs já aplica a migration
automaticamente no banco (db.Database.Migrate()) e popula os dados
iniciais (seed) de jogos e desenvolvedoras.

Delete este arquivo LEIA-ME.txt depois de gerar a migration de verdade.
